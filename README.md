# 🕹️ Metroid 2D - Basic Prototype

Este proyecto es un prototipo funcional de un juego de plataformas en 2D inspirado en la estética de Metroid. Se centra en las mecánicas fundamentales de movimiento, interacción con el entorno y sistema de colisiones.

---

## 🚀 Funcionalidades Implementadas

- **Sistema de Movimiento:** Control fluido del personaje (caminar, saltar y caídas con físicas).
- **Entidades Enemigas:** Implementación de IA básica para enemigos con patrullaje y detección de contacto.
- **Gestión de Audio:** Sistema de sonido integrado para acciones del jugador y eventos de ambiente.
- **Detección de Colisiones:** Sistema robusto de interacción entre el jugador, los enemigos y el escenario.
- **Animaciones:** Transiciones de estados (Idle, Run, Jump) vinculadas a las acciones del jugador.

---

## 🛠️ Stack Tecnológico

- **Motor:** Unity 2D
- **Lenguaje:** C#
- **Físicas:** RigidBody2D & BoxColliders
- **Audio:** AudioSource

---

## 📂 Estructura del Proyecto

- `/Scripts`: Lógica del jugador, controladores de enemigos y gestión de sonido.
- `/Sprites`: Assets visuales y animaciones.
- `/Sounds`: Efectos de sonido y música de fondo.
